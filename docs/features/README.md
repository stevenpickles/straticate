# Feature documentation

One document per numbered feature: `NNN-short-description.md` (matching the
branch name). Create it from the template below in the same PR that implements
the feature, and update the corresponding ledger row in
[ROADMAP.md](../../ROADMAP.md).

## Template

```markdown
# [NNN] Feature Title

Branch: `NNN-short-description`
Status: PLANNED | READY | IN PROGRESS | PR OPEN | BLOCKED | MERGED
Dependencies: NNN, NNN (or —)
PR: #… (when open)

## Objective

One or two sentences: what exists after this feature that didn't before.

## Scope

- …

## Out of scope

- …

## Expected modules/files

- …

## Acceptance criteria

- [ ] …

## Required tests

- …

## Notes / decisions

Anything future features or agents need to know.
```
